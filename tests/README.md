# Тесты

Проверяют ожидаемое поведение и корректность — прежде всего математику КБЖУ, на которой держится весь продукт.

## Запуск

```bash
npm test          # прогон всех тестов (Vitest)
npm test -- --watch   # режим наблюдения
```

## Структура

| Папка | Что покрывает |
|-------|---------------|
| `unit/` | Чистые функции `src/calc.js`: формула Миффлина, расчёт нормы под цель, адаптивная коррекция и её лимиты безопасности |
| `integration/` | (заготовка) сценарии «онбординг → расчёт → запись в БД → пересчёт». Добавлять по мере стабилизации `db.js` |

## Принципы

- **Тесты рядом с кодом, который держит продукт.** Формулы КБЖУ — критический путь: ошибка тут = пользователь не наберёт/не сбросит вес и потеряет доверие. Поэтому `calc.js` покрыт в первую очередь.
- **Опорные значения зафиксированы** на эталонном профиле (мужчина 63 кг / 178 см / 25 лет / средняя активность). Меняешь формулу — тест должен осознанно обновиться, а не «подгоняться».
- Тестируем чистую логику; UI проверяется вручную до появления e2e.
